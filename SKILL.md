# Graphify Knowledge Graph Skill

This skill teaches agents to leverage a **pre-computed knowledge graph** generated by [graphifyy](https://pypi.org/project/graphifyy/). Instead of reading dozens of files to understand a codebase, the agent reads the graph once and queries its structure.

## When to Use

- You're working in a repo that has a `graphify-out/` directory
- You want to understand the codebase architecture without reading every file (token savings)
- You need to find the right file to edit for a given task
- You're planning a refactor and need to understand dependencies
- You want to detect import cycles, god modules, or isolated components
- You're onboarding to a new project

## How It Works

Graphify produces a **knowledge graph** with:

- **Nodes**: files, functions, classes, methods, and external dependencies (1000 per 200 files)
- **Edges**: `contains`, `imports`, `calls`, `uses`, `inherits`, `references` (+ inferred AI relations)
- **Communities**: automatically detected logical groupings of related code (cohesion scores 0–1)
- **God Nodes**: the most-connected abstractions (highest degree centrality)
- **Surprising Connections**: AI-inferred edges that cross community boundaries

### Graph File Locations

| File | Purpose |
|---|---|
| `graphify-out/graph.json` | Full graph data (nodes, links, communities) — **main file to query** |
| `graphify-out/GRAPH_REPORT.md` | Human-readable summary — read first for quick orientation |
| `graphify-out/graph.html` | Interactive visualization (open in browser) |

## How to Use (Step by Step)

### Step 1: Check If a Graph Exists

Check for `graphify-out/GRAPH_REPORT.md` in the project root. If it exists, the graph is ready.

Read it first — it gives you the full overview in ~3KB instead of reading hundreds of source files.

```markdown
## Example output when reading GRAPH_REPORT.md:
- 1000 nodes · 2323 edges · 56 communities
- God Nodes: SeleniumEngine (52 edges), StaticEngine (38), call_tool() (37)
- Import Cycles: None detected
- 3 isolated nodes (possible dead code or missing edges)
- 109 AI-inferred edges (avg confidence 0.56)
```

### Step 2: Load the Graph Structure

Read the first 50 lines of `graphify-out/graph.json` to understand the schema, then query the graph programmatically.

```python
import json, subprocess, sys
from collections import Counter

with open("graphify-out/graph.json") as f:
    g = json.load(f)

nodes = g["nodes"]
links = g["links"]

# Build lookup: id -> node
node_map = {n["id"]: n for n in nodes}

# Build adjacency
adj = {}
for link in links:
    adj.setdefault(link["source"], []).append(link)
    adj.setdefault(link["target"], []).append(link)
```

### Step 3: Answer Common Questions

#### "Where should I edit to add feature X?"

```python
# Search nodes by label or norm_label
query = sys.argv[1].lower()
matches = [n for n in nodes if query in n.get("label","").lower() or query in n.get("norm_label","").lower()]
for n in matches[:10]:
    print(f"{n['label']} -> {n.get('source_file','?')}:{n.get('source_location','?')} (community {n.get('community')})")
```

Use this to find the right file instantly instead of grepping blindly.

#### "What does this module depend on?"

```python
target_id = sys.argv[1]
for link in links:
    if link["source"] == target_id and link["relation"] in ("imports", "imports_from", "uses", "calls"):
        other = node_map.get(link["target"], {})
        print(f"  {link['relation']} -> {other.get('label','?')} ({other.get('source_file','?')})")
```

#### "What depends on this module?"

```python
target_id = sys.argv[1]
for link in links:
    if link["target"] == target_id and link["relation"] in ("imports", "imports_from", "uses", "calls"):
        other = node_map.get(link["source"], {})
        print(f"  {other.get('label','?')} ({other.get('source_file','?')}) --{link['relation']}--> {target_id}")
```

#### "Show me the architecture (communities overview)"

```python
communities = {}
for n in nodes:
    c = n.get("community", -1)
    communities.setdefault(c, []).append(n["label"])

for c in sorted(communities):
    members = communities[c]
    print(f"Community {c}: {len(members)} nodes")
    print(f"  Top: {', '.join(members[:5])}")
```

#### "Are there import cycles?"

Read the GRAPH_REPORT.md — cycles are detected automatically:

```
## Import Cycles
- None detected.
```

If cycles exist, the report lists them with file paths.

#### "Which nodes are most central (god nodes)?"

```python
degree = Counter()
for link in links:
    degree[link["source"]] += 1
    degree[link["target"]] += 1

for node_id, deg in degree.most_common(10):
    n = node_map.get(node_id, {})
    print(f"{n.get('label','?')} - {deg} connections ({n.get('source_file','?')})")
```

### Step 4: Use Insights for Code Improvement

| Graph Insight | Action |
|---|---|
| God node with 50+ edges | This is critical — add tests before touching it |
| Community cohesion < 0.10 | Group is too loose — consider splitting or documenting |
| Community cohesion > 0.70 | Group is cohesive — keep those files together |
| Inferred edge (confidence < 0.5) | Verify if the connection is real; add explicit import if yes |
| Isolated node (≤1 connection) | Possibly dead code — consider removing or documenting |
| Cross-community bridge | High-risk change area — add integration tests |

### Step 5: Update the Graph

After making code changes, update the graph so it stays fresh:

```bash
# Check if update is needed
CURRENT=$(git rev-parse HEAD)
GRAPH_COMMIT=$(python3 -c "import json; print(json.load(open('graphify-out/graph.json')).get('built_at_commit',''))")
if [ "$CURRENT" != "$GRAPH_COMMIT" ]; then
    echo "Graph is stale. Run: graphify update ."
fi
```

```bash
graphify update .   # No API cost — purely local AST analysis
```

## Token Savings Analysis

Without graph: agent reads top 5 files in each relevant community (~15 files × 200 lines × 2KB = ~30KB or ~7500 tokens)

With graph: agent reads GRAPH_REPORT.md (3KB) + graph.json head (5KB) + queries specific nodes (~2KB) = ~10KB or ~2500 tokens

**Savings: ~65% on code understanding tasks.**

## Example Workflow

```
User: "Add a new MCP server for image processing"

Agent (using this skill):
1. Read GRAPH_REPORT.md → sees server pattern (run_server, FastMCP, communities 3,8)
2. Query graph for "run_server" → finds it in community 8 with 38 nodes
3. Query what run_server depends on → sees scrape.py, browser.py, doc.py, db
4. Check god nodes → RouterEngine (24 edges) connects all servers
5. Read template from existing server (e.g., servers/doc.py) — minimal file reads
6. Implement following the established pattern

Result: ~5 file reads instead of ~20 — same quality, 4x faster
```
